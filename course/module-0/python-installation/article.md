# Установка Python

Для курса Python устанавливать не обязательно: задачи запускаются на наших серверах, а любой код можно выполнить в **<a href="https://python-academy.org/ru/sandbox" target="_blank">Песочнице</a>**. Так что если вам не терпится начать — смело листайте дальше, эта глава никуда не денется.

Но рано или поздно захочется писать код у себя: свои файлы, свои проекты, без вкладки в браузере. Тогда возвращайтесь сюда — ниже короткий путь от «ничего нет» до «всё работает» 🚀.

## Шаг 1. Проверьте, вдруг Python уже есть

Python мог приехать вместе с системой или установиться раньше — на macOS и Linux он есть почти всегда. Проверять будем в терминале: это окно, где команды набирают текстом, а не мышкой.

- **Windows** — нажмите `Win`, наберите «PowerShell» и откройте его.
- **macOS** — нажмите `Cmd + пробел`, наберите «Терминал» и откройте его.
- **Linux** — обычно `Ctrl + Alt + T`.

Наберите команду и нажмите `Enter`:

**macOS / Linux**

```sh
python3 --version
```

**Windows**

```powershell
python --version
```

Если в ответ пришёл номер версии — например, `Python 3.12.4` — всё уже на месте, и шаг 2 можно пропустить. Годится любая версия, которая начинается с цифры 3.

Ответ вида «команда не найдена» тоже нормальный: значит, Python просто ещё не установлен. Идём дальше.

## Шаг 2. Установите Python

### Windows

1. Откройте **<a href="https://www.python.org/downloads/windows/" target="_blank">python.org → Downloads → Windows</a>** и скачайте установщик.
2. Запустите его.
3. На первом же экране поставьте галочку **«Add python.exe to PATH»** — и только потом нажимайте **Install Now**.
4. Дождитесь конца установки и закройте установщик.

Про эту галочку стоит сказать отдельно, потому что её легко пропустить, а последствия неприятные. PATH — это список папок, в которых система ищет программы, когда вы набираете команду. Без галочки Python установится, но система про него не узнает: вы наберёте `python`, а в ответ получите «команда не найдена». Поставить галочку — секунда, а искать потом причину можно полчаса.

Если галочку всё-таки пропустили, проще всего запустить установщик заново и выбрать **Modify**.

### macOS

Способ первый, без лишних инструментов: скачайте установщик с **<a href="https://www.python.org/downloads/macos/" target="_blank">python.org → Downloads → macOS</a>**, откройте `.pkg` и пройдите по шагам установщика.

Способ второй — через **<a href="https://brew.sh/" target="_blank">Homebrew</a>**, если он у вас уже стоит (проверить: `brew -v`):

```bash
brew install python
```

### Linux

Команда зависит от дистрибутива:

- **Ubuntu / Debian:**

    ```bash
    sudo apt update
    sudo apt install -y python3 python3-pip
    ```

- **Fedora:**

    ```bash
    sudo dnf install -y python3 python3-pip
    ```

- **Arch Linux:**

    ```bash
    sudo pacman -S python python-pip
    ```

## Шаг 3. Проверьте, что всё заработало

Закройте терминал и откройте заново — он должен узнать о новой программе. Теперь та же команда, что и в шаге 1:

**macOS / Linux**

```sh
python3 --version
```

**Windows**

```powershell
python --version
```

Номер версии в ответ — готово, Python ваш.

Если Windows отвечает «команда не найдена», попробуйте `py --version`. Не помогло — почти наверняка дело в той самой галочке PATH: перезапустите установщик и выберите **Modify**. Иногда достаточно просто перезайти в систему.

На macOS и Linux команда называется `python3`, а не `python` — это не поломка, а норма: короткое имя `python` там исторически занято.

Удачи! ✨
