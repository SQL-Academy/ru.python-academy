# Списки в Python

Допустим, вы ведёте список покупок. Можно завести переменную под каждый товар: `item1`, `item2`, `item3`. Но это быстро превращается в кашу: вставить пункт в середину нельзя, посчитать количество товаров нельзя, пройтись по всем подряд тоже. Нужна одна переменная, которая хранит много значений по порядку. Это и есть список.

```python
shopping = ["хлеб", "молоко", "яйца"]
print(shopping)
<output>
['хлеб', 'молоко', 'яйца']
</output>
```

> Список (list) — это упорядоченная изменяемая коллекция элементов. Под одним именем лежит сразу несколько значений, у каждого есть своя позиция, и набор можно менять: добавлять, удалять, переставлять.

Из этого определения вытекают четыре свойства, на которые мы будем опираться дальше:

- **Порядок сохраняется** — элементы лежат в том порядке, в каком вы их добавили
- **Список изменяемый** — после создания в него можно добавлять и удалять элементы
- **Доступ по индексу** — к любому элементу можно обратиться по его позиции
- **Дубликаты разрешены** — одно и то же значение может встречаться несколько раз

## Создание списков

Существует несколько способов создания списков в Python:

### С помощью квадратных скобок \[]

```python
# Пустой список
empty_list = []
print(empty_list)
<output>
[]
</output>

# Список чисел
numbers = [1, 2, 3, 4, 5]
print(numbers)
<output>
[1, 2, 3, 4, 5]
</output>

# Список разных типов данных
mixed = [1, "привет", True, 3.14]
print(mixed)
<output>
[1, 'привет', True, 3.14]
</output>

# Вложенные списки (список списков)
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
print(matrix)
<output>
[[1, 2, 3], [4, 5, 6], [7, 8, 9]]
</output>
```

### С помощью конструктора list()

```python
# Создание пустого списка
empty_list = list()
print(empty_list)
<output>
[]
</output>

# Создание списка из строки (каждый символ становится элементом)
chars = list("Python")
print(chars)
<output>
['P', 'y', 't', 'h', 'o', 'n']
</output>

# Создание списка из других итерируемых объектов
tuple_to_list = list((1, 2, 3))
print(tuple_to_list)
<output>
[1, 2, 3]
</output>
```

## Доступ к элементам списка

### Индексация

В Python индексация начинается с 0, то есть первый элемент имеет индекс 0, второй — 1, и так далее:

```python
fruits = ["яблоко", "банан", "вишня", "груша", "апельсин"]

# Получение элементов по индексу
first_fruit = fruits[0]
print(f"Первый фрукт: {first_fruit}")
<output>
Первый фрукт: яблоко
</output>

# Отрицательные индексы для доступа с конца списка
last_fruit = fruits[-1]
print(f"Последний фрукт: {last_fruit}")
<output>
Последний фрукт: апельсин
</output>

second_last = fruits[-2]
print(f"Предпоследний фрукт: {second_last}")
<output>
Предпоследний фрукт: груша
</output>
```

### Срезы (slices)

Срезы позволяют получить подсписок, указав начальный и конечный индексы:

```python
fruits = ["яблоко", "банан", "вишня", "груша", "апельсин"]

# Синтаксис среза: список[начало:конец:шаг]
# Начало включается, конец не включается!

# Первые три элемента
first_three = fruits[0:3]
print(f"Первые три фрукта: {first_three}")
<output>
Первые три фрукта: ['яблоко', 'банан', 'вишня']
</output>

# То же самое, но начальный индекс можно опустить, если он 0
first_three = fruits[:3]
print(f"Первые три фрукта: {first_three}")
<output>
Первые три фрукта: ['яблоко', 'банан', 'вишня']
</output>

# Каждый второй элемент
every_second = fruits[::2]
print(f"Каждый второй фрукт: {every_second}")
<output>
Каждый второй фрукт: ['яблоко', 'вишня', 'апельсин']
</output>

# Разворот списка
reversed_list = fruits[::-1]
print(f"Список в обратном порядке: {reversed_list}")
<output>
Список в обратном порядке: ['апельсин', 'груша', 'вишня', 'банан', 'яблоко']
</output>
```

## Перебор списка

Обращаться по индексу удобно, когда нужен один-два элемента. Но чтобы пройтись по всем, есть путь короче — цикл `for`, который вы уже знаете:

```python
fruits = ["яблоко", "банан", "вишня"]

for fruit in fruits:
    print(f"Фрукт: {fruit}")
<output>
Фрукт: яблоко
Фрукт: банан
Фрукт: вишня
</output>
```

Сколько в списке элементов, показывает функция `len()`:

```python
fruits = ["яблоко", "банан", "вишня"]
print(f"Всего фруктов: {len(fruits)}")
<output>
Всего фруктов: 3
</output>
```

Иногда вместе с элементом нужен и его индекс. Заводить для этого отдельную переменную-счётчик не нужно — есть `enumerate()`, который выдаёт пару «индекс и значение»:

```python
fruits = ["яблоко", "банан", "вишня"]

for index, fruit in enumerate(fruits):
    print(f"Индекс {index}: {fruit}")
<output>
Индекс 0: яблоко
Индекс 1: банан
Индекс 2: вишня
</output>
```

## Изменение элементов списка

Главное отличие списков от строк: **списки изменяемые** (mutable). Строку поменять «на месте» нельзя — приходится создавать новую (вспомните урок про строки). А вот элементы списка можно изменять, добавлять и удалять прямо в существующем объекте:

```python
fruits = ["яблоко", "банан", "вишня"]

# Изменение элемента
fruits[0] = "киви"
print(fruits)
<output>
['киви', 'банан', 'вишня']
</output>

# Изменение нескольких элементов с помощью среза
numbers = [1, 2, 3, 4, 5]
numbers[1:4] = [20, 30, 40]
print(numbers)
<output>
[1, 20, 30, 40, 5]
</output>

# Можно даже заменить несколько элементов на другое количество
numbers = [1, 2, 3, 4, 5]
numbers[1:4] = [20, 30]
print(numbers)
<output>
[1, 20, 30, 5]
</output>
```

## Основные методы списков

Python предоставляет множество встроенных методов для работы со списками:

### Добавление элементов

```python
fruits = ["яблоко", "банан"]

# Добавление элемента в конец списка
fruits.append("вишня")
print(fruits)
<output>
['яблоко', 'банан', 'вишня']
</output>

# Вставка элемента на определенную позицию
fruits.insert(1, "апельсин")
print(fruits)
<output>
['яблоко', 'апельсин', 'банан', 'вишня']
</output>

# Добавление элементов из другого списка
more_fruits = ["груша", "виноград"]
fruits.extend(more_fruits)
print(fruits)
<output>
['яблоко', 'апельсин', 'банан', 'вишня', 'груша', 'виноград']
</output>

# Объединение списков с помощью оператора +
combined = fruits + ["ананас", "манго"]
print(combined)
<output>
['яблоко', 'апельсин', 'банан', 'вишня', 'груша', 'виноград', 'ананас', 'манго']
</output>
```

### Удаление элементов

```python
fruits = ["яблоко", "банан", "вишня", "апельсин", "банан"]

# Удаление элемента по значению (удаляет только первое вхождение)
fruits.remove("банан")
print(fruits)
<output>
['яблоко', 'вишня', 'апельсин', 'банан']
</output>

# Удаление элемента по индексу и возврат его значения
removed = fruits.pop(1)
print(f"Удален: {removed}")
<output>
Удален: вишня
</output>
print(f"Список после удаления: {fruits}")
<output>
Список после удаления: ['яблоко', 'апельсин', 'банан']
</output>

# Если индекс не указан, pop() удаляет и возвращает последний элемент
last = fruits.pop()
print(f"Последний элемент: {last}")
<output>
Последний элемент: банан
</output>
print(fruits)
<output>
['яблоко', 'апельсин']
</output>

# Удаление всех элементов из списка
fruits.clear()
print(f"Пустой список: {fruits}")
<output>
Пустой список: []
</output>

# Оператор del для удаления элементов по индексу или срезу
numbers = [1, 2, 3, 4, 5]
del numbers[0]
print(numbers)
<output>
[2, 3, 4, 5]
</output>

del numbers[1:3]
print(numbers)
<output>
[2, 5]
</output>
```

### Поиск и подсчет элементов

```python
fruits = ["яблоко", "банан", "вишня", "банан", "груша"]

# Проверка наличия элемента в списке
print("банан" in fruits)
<output>
True
</output>
print("арбуз" in fruits)
<output>
False
</output>

# Поиск индекса первого вхождения элемента
banana_index = fruits.index("банан")
print(f"Индекс первого банана: {banana_index}")
<output>
Индекс первого банана: 1
</output>

# Подсчет количества вхождений элемента
banana_count = fruits.count("банан")
print(f"Количество бананов: {banana_count}")
<output>
Количество бананов: 2
</output>
```

### Сортировка и разворот

```python
# Сортировка списка (изменяет исходный список)
numbers = [3, 1, 4, 1, 5, 9, 2]
numbers.sort()
print(f"Отсортированный список: {numbers}")
<output>
Отсортированный список: [1, 1, 2, 3, 4, 5, 9]
</output>

# Сортировка в обратном порядке
numbers.sort(reverse=True)
print(f"Обратная сортировка: {numbers}")
<output>
Обратная сортировка: [9, 5, 4, 3, 2, 1, 1]
</output>

# Если не хотите изменять исходный список, используйте sorted()
original = [3, 1, 4, 1, 5]
sorted_list = sorted(original)
print(f"Оригинал: {original}")
<output>
Оригинал: [3, 1, 4, 1, 5]
</output>
print(f"Отсортированная копия: {sorted_list}")
<output>
Отсортированная копия: [1, 1, 3, 4, 5]
</output>
```

## Копирование списков

Это одна из самых частых причин багов у новичков: присваивание списка **не создаёт копию**, обе переменные указывают на один и тот же объект в памяти. Если изменить список через одну переменную, изменение увидит и другая.

![Присваивание vs копирование: при reference = original обе переменные указывают на одну коробку, при copy = original.copy() создаётся новая коробка](https://python-academy.org/static/guidePage/lists/copy-vs-reference-ru.webp "Присваивание vs копирование")

```python
# Создаем список
original = [1, 2, 3]

# Присваивание не создает копию — обе переменные указывают на один список
reference = original
reference.append(4)
print(f"Оригинал после изменения ссылки: {original}")
<output>
Оригинал после изменения ссылки: [1, 2, 3, 4]
</output>

# Правильные способы копирования списка:
# 1. Метод copy()
copy1 = original.copy()

# 2. Использование среза [:]
copy2 = original[:]

# 3. Функция list()
copy3 = list(original)

# Проверим, что копии не связаны с оригиналом
copy1.append(5)
print(f"Оригинал: {original}")
<output>
Оригинал: [1, 2, 3, 4]
</output>
print(f"Копия 1: {copy1}")
<output>
Копия 1: [1, 2, 3, 4, 5]
</output>
```

## Списковые включения

Очень частая задача: взять один список и сделать из него другой. В лоб это несколько строк — завести пустой список, пройти циклом, добавлять по одному:

```python
squares = []
for i in range(10):
    squares.append(i**2)
print(squares)
<output>
[0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
</output>
```

Настолько частая, что для неё придумали короткую запись — **списковое включение**. Тот же результат в одну строку:

```python
squares = [i**2 for i in range(10)]
print(squares)
<output>
[0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
</output>
```

Читать её удобнее не слева направо: сначала `for i in range(10)` — откуда берём значения, потом `i**2` — что кладём в новый список. В конце можно добавить условие, и тогда попадут не все значения, а только подходящие:

```python
even_squares = [i**2 for i in range(10) if i % 2 == 0]
print(even_squares)
<output>
[0, 4, 16, 36, 64]
</output>
```

Соблазн запихнуть в одну строку всё подряд велик, но включение хорошо ровно до тех пор, пока читается с одного взгляда. Если внутрь просятся два условия и вложенный цикл — обычный `for` будет понятнее и вам, и тому, кто откроет код через полгода.

## Практический пример использования списка

```python
# Список студентов и их оценок
students = ["Анна", "Иван", "Мария", "Петр", "Елена"]
grades = [95, 82, 90, 78, 88]

# Нахождение студента с наивысшим баллом
highest_score = max(grades)
top_student_index = grades.index(highest_score)
print(f"Лучший студент: {students[top_student_index]} с оценкой {highest_score}")
<output>
Лучший студент: Анна с оценкой 95
</output>
```

## Проверка понимания

**Какой из следующих способов правильно создаст копию списка, не связанную с оригиналом?**

1. copy_list = original_list — Это не создает копию, а лишь дает другое имя тому же списку. Изменения в copy_list будут отражаться на original_list.

2. **Правильный ответ:** copy_list = original_list.copy() — Метод .copy() создает новую копию списка. Изменения в копии не повлияют на оригинал (однако будьте осторожны с вложенными объектами - это неглубокая копия).

3. **Правильный ответ:** copy_list = original_list\[:] — Использование среза \[:] создает новую копию всего списка. Это один из правильных способов создания копии в Python.

4. **Правильный ответ:** copy_list = list(original_list) — Функция list() создает новый список на основе существующего, что является правильным способом копирования.
