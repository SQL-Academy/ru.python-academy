# Строковые данные в Python

Почти всё, что программа показывает человеку и получает от него обратно, — это текст: имя в форме регистрации, сообщение об ошибке, строка из файла. В Python текст хранится в строках — значениях типа `str`.

Строка — это просто последовательность символов, и с ней можно многое: склеивать, резать на части, искать внутри, подставлять значения переменных. С создания и начнём.

## Как создавать строки в Python

Python предлагает несколько способов создания строк. Можно использовать одинарные, двойные или тройные кавычки:

```python
# Строки в одинарных кавычках
single_quotes = 'Привет, мир!'
print(single_quotes)
<output>
Привет, мир!
</output>

# Строки в двойных кавычках
double_quotes = "Hello, world"
print(double_quotes)
<output>
Hello, world
</output>

# Многострочные строки в тройных кавычках
multi_line = """Рецепт кофе:
1. Вскипятить воду
2. Залить молотый кофе
3. Подождать 4 минуты"""
print(multi_line)
<output>
Рецепт кофе:
1. Вскипятить воду
2. Залить молотый кофе
3. Подождать 4 минуты
</output>
```

Выбор типа кавычек зависит от ситуации:

- Одинарные (`'`) и двойные (`"`) кавычки работают одинаково
- Если в строке уже есть одинарные кавычки, удобнее обернуть её в двойные, и наоборот
- Тройные кавычки (`"""` или `'''`) подходят для многострочного текста

### Экранирование символов

Иногда нам нужно включить в строку особые символы, например, кавычки или перенос строки. Для этого используются последовательности с обратной косой чертой (`\`):

```python
# Использование кавычек внутри строк с экранированием
quote_inside = "Он сказал: \"Привет!\""
print(quote_inside)
<output>
Он сказал: "Привет!"
</output>

path = "C:\\Program Files\\Python"
print(path)
<output>
C:\Program Files\Python
</output>

# Часто используемые последовательности экранирования
newline = "Первая строка.\nВторая строка."  # \n - перенос строки
print(newline)
<output>
Первая строка.
Вторая строка.
</output>

tab = "Имя:\tИван"  # \t - табуляция
print(tab)
<output>
Имя:	Иван
</output>
```

Полезные последовательности экранирования:

- `\n` для переноса строки
- `\t` для табуляции
- `\\` для обратной косой черты
- `\'` для одинарной кавычки
- `\"` для двойной кавычки

### Raw-строки

Когда обратных косых черт много — например, в пути к файлу на Windows — экранировать каждую утомительно. Префикс `r` перед строкой отключает экранирование: все символы берутся буквально.

```python
# Обычную строку пришлось бы писать с двойными обратными слешами
raw_path = r"C:\Users\Documents\file.txt"
print(raw_path)
<output>
C:\Users\Documents\file.txt
</output>
```

## Неизменяемость строк

Строки в Python являются **неизменяемыми** (immutable). Это значит, что после создания строки её нельзя поменять «на месте»: любая операция, которая выглядит как изменение, на самом деле создаёт новую строку.

Попытка изменить символ по индексу падает с ошибкой:

```python
language = "Python"

try:
    language[0] = "J"
except TypeError as e:
    print(f"Ошибка: {e}")
<output>
Ошибка: 'str' object does not support item assignment
</output>
```

Чтобы получить «изменённую» строку, нужно собрать новую и присвоить её — либо в ту же переменную, либо в другую:

```python
language = "Python"
language = "J" + "ython"
print(language)
<output>
Jython
</output>
```

Это правило касается всех операций над строками: `+`, `.upper()`, `.replace()` и другие возвращают новую строку, а не меняют исходную.

## Основные операции со строками

### Сложение строк (конкатенация)

Строки можно складывать с помощью оператора `+`, чтобы создавать новые строки:

```python
first_name = "Иван"
last_name = "Петров"
full_name = first_name + " " + last_name
print(full_name)
<output>
Иван Петров
</output>

greeting = "Привет, " + full_name + "!"
print(greeting)
<output>
Привет, Иван Петров!
</output>
```

### Повторение строк

С помощью оператора `*` можно повторить строку несколько раз:

```python
border = "=" * 20
print(border)
<output>
====================
</output>
```

### Длина строки

Количество символов в строке узнаём через встроенную функцию `len()`:

```python
word = "Python"
print(len(word))
<output>
6
</output>

empty = ""
print(len(empty))
<output>
0
</output>
```

### Доступ к отдельным символам

В строке к каждому символу можно обратиться по его позиции (индексу). Индексация начинается с 0, а отрицательные индексы отсчитываются с конца:

![Индексы строки Python: положительные 0–5 над буквами, отрицательные -6…-1 под ними. Срез word[1:4] выделяет y, t, h](https://python-academy.org/static/guidePage/string-data-types/indexing-ru.webp "Индексы и срезы строки")

```python
word = "Python"
first_letter = word[0]
second_letter = word[1]
last_letter = word[5]

print(f"Первая буква: {first_letter}")
print(f"Вторая буква: {second_letter}")
print(f"Последняя буква: {last_letter}")
<output>
Первая буква: P
Вторая буква: y
Последняя буква: n
</output>

# Можно также использовать отрицательные индексы для отсчета с конца
last_letter = word[-1]
second_last_letter = word[-2]
print(f"Последняя буква (с конца): {last_letter}")
print(f"Предпоследняя буква: {second_last_letter}")
<output>
Последняя буква (с конца): n
Предпоследняя буква: o
</output>
```

### Получение части строки (срезы)

В Python есть мощный приём для работы со строками: срезы (slices). Они позволяют извлекать подстроки, указывая начальный и конечный индексы:

```python
message = "Python Programming"

# Синтаксис среза: строка[начало:конец:шаг]
# начало включается, конец исключается

first_word = message[0:6]     # первые 6 символов
print(f"Первое слово: {first_word}")
<output>
Первое слово: Python
</output>

second_word = message[7:]      # от 7-го до конца
print(f"Второе слово: {second_word}")
<output>
Второе слово: Programming
</output>

prefix = message[:6]           # от начала до 6-го (не включая 6-й)
print(f"Префикс: {prefix}")
<output>
Префикс: Python
</output>

every_second = message[::2]    # каждый второй символ
print(f"Каждая вторая буква: {every_second}")
<output>
Каждая вторая буква: Pto rgamn
</output>

reversed_string = message[::-1]  # строка задом наперед
print(f"В обратном порядке: {reversed_string}")
<output>
В обратном порядке: gnimmargorP nohtyP
</output>
```

Срезы гибкие:

- Если не указать начальный индекс, срез начнется с начала строки
- Если не указать конечный индекс, срез продолжится до конца строки
- Отрицательный шаг позволяет обходить строку в обратном порядке

## Полезные методы для работы со строками

Python предоставляет множество встроенных методов для работы со строками. Рассмотрим самые полезные.

### Изменение регистра текста

```python
text = "Hello PYTHON world"

upper_case = text.upper()
print(f"Верхний регистр: {upper_case}")
<output>
Верхний регистр: HELLO PYTHON WORLD
</output>

lower_case = text.lower()
print(f"Нижний регистр: {lower_case}")
<output>
Нижний регистр: hello python world
</output>

title_case = text.title()
print(f"Каждое слово с заглавной: {title_case}")
<output>
Каждое слово с заглавной: Hello Python World
</output>

capitalized = text.capitalize()
print(f"Только первая буква заглавная: {capitalized}")
<output>
Только первая буква заглавная: Hello python world
</output>
```

### Поиск и замена в строках

```python
text = "Python это отличный язык программирования"

# Поиск подстроки
position = text.find("отличный")
print(f"Слово 'отличный' начинается с позиции: {position}")
<output>
Слово 'отличный' начинается с позиции: 11
</output>

count = text.count("о")
print(f"Буква 'о' встречается {count} раза")
<output>
Буква 'о' встречается 4 раза
</output>

# Проверка начала и конца строки
starts_with = text.startswith("Python")
print(f"Строка начинается с 'Python': {starts_with}")
<output>
Строка начинается с 'Python': True
</output>

ends_with = text.endswith("!")
print(f"Строка заканчивается на '!': {ends_with}")
<output>
Строка заканчивается на '!': False
</output>

# Проверка наличия подстроки
contains = "отличный" in text
print(f"Строка содержит слово 'отличный': {contains}")
<output>
Строка содержит слово 'отличный': True
</output>

# Замена подстрок
new_text = text.replace("отличный", "прекрасный")
print(f"Текст после замены: {new_text}")
<output>
Текст после замены: Python это прекрасный язык программирования
</output>
```

### Разделение и объединение строк

```python
# Разделение строки на список слов
sentence = "Python это отличный язык программирования"
words = sentence.split()
print(f"Список слов: {words}")
<output>
Список слов: ['Python', 'это', 'отличный', 'язык', 'программирования']
</output>

# Разделение по конкретному разделителю
csv_data = "яблоко,банан,вишня"
fruits = csv_data.split(",")
print(f"Список фруктов: {fruits}")
<output>
Список фруктов: ['яблоко', 'банан', 'вишня']
</output>

# Объединение списка в строку
words_to_join = ["Python", "это", "здорово"]
joined_sentence = " ".join(words_to_join)
print(f"Объединенное предложение: {joined_sentence}")
<output>
Объединенное предложение: Python это здорово
</output>

# Объединение с другим разделителем
path_parts = ["C:", "Users", "Username", "Documents"]
path = "\\".join(path_parts)
print(f"Путь к файлу: {path}")
<output>
Путь к файлу: C:\Users\Username\Documents
</output>
```

### Удаление лишних символов

Для очистки текста от лишних пробелов или других символов:

```python
text_with_spaces = "   Python   "

# Удаление пробелов с обоих концов
cleaned = text_with_spaces.strip()
print(f"Без пробелов: '{cleaned}'")
<output>
Без пробелов: 'Python'
</output>

left_cleaned = text_with_spaces.lstrip()
print(f"Без пробелов слева: '{left_cleaned}'")
<output>
Без пробелов слева: 'Python   '
</output>

right_cleaned = text_with_spaces.rstrip()
print(f"Без пробелов справа: '{right_cleaned}'")
<output>
Без пробелов справа: '   Python'
</output>

# Удаление конкретных символов
text_with_dots = "...Python..."
without_dots = text_with_dots.strip('.')
print(f"Без точек: '{without_dots}'")
<output>
Без точек: 'Python'
</output>
```

### Цепочки методов

Каждый строковый метод возвращает новую строку (помним про неизменяемость). А значит, их можно вызывать подряд через точку — результат одного сразу передаётся следующему. Это называется **цепочкой методов**.

Например, нужно нормализовать пользовательский ввод: убрать лишние пробелы по краям и привести к нижнему регистру.

В три шага через временные переменные:

```python
raw_input = "  Hello  "
without_spaces = raw_input.strip()
normalized = without_spaces.lower()
```

Цепочкой в одну строку:

```python
raw_input = "  Hello  "
normalized = raw_input.strip().lower()
print(f"'{normalized}'")
<output>
'hello'
</output>
```

Цепочки работают, потому что после `strip()` мы получаем новую строку, у которой тут же вызывается `lower()`. Это типичный паттерн Python-кода: вместо ведра промежуточных переменных — одна выразительная цепочка.

## Форматирование строк

Часто нужно вставлять значения переменных в текст. В современном Python для этого используют **f-строки**:

```python
name = "Анна"
age = 25

# Просто добавьте 'f' перед строкой и вставляйте переменные в {}
greeting = f"Привет, меня зовут {name} и мне {age} лет."
print(greeting)
<output>
Привет, меня зовут Анна и мне 25 лет.
</output>

# Внутри {} можно вставлять любые выражения
price = 19.99
quantity = 3
total = f"Итого: {price * quantity:.2f} руб."
print(total)
<output>
Итого: 59.97 руб.
</output>
```

Помимо f-строк существуют ещё два способа форматирования, которые встречаются в старом коде: метод `"...".format(...)` и оператор `"..." % (...)`. В новом коде их обычно не используют: f-строки проще и быстрее.

## Проверка понимания

Давайте проверим, насколько хорошо вы поняли работу со строками:

**Что будет результатом выполнения следующего кода?**

```python
text = "Python"
result = text[1:4]
```

1. "Pyt" — Срез \[1:4] начинается с индекса 1 (второй символ) и заканчивается перед индексом 4.

2. **Правильный ответ:** "yth" — Срез \[1:4] в строке "Python" возвращает символы с индексами 1, 2 и 3, то есть "yth".

3. "ytho" — Срез \[1:4] извлекает символы с индексами от 1 до 3 включительно, не включая символ с индексом 4.

4. "Pyth" — Срез \[1:4] начинается со второго символа (индекс 1), а не с первого.
